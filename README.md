# Spatial Evidence Lab

Official Spatial Evidence Lab research portfolio.

## Site architecture

- `/` — organisation research landing page
- `/projects/` — master project catalogue
- `/projects/sel-XXX-.../` — canonical project pages
- `/about/` — organisation information
- `/css/sel-theme.css` — master design tokens
- `/css/sel-components.css` — shared components
- `/css/sel-project.css` — project-page system
- `/css/portfolio.css` — homepage and catalogue layouts
- `/projects.json` — project catalogue metadata
- `/projects/_template/` — source template for new project pages

## Project-page system

Every project follows the same evidence architecture:

1. Overview
2. Study area
3. Method
4. Data & sources
5. Evidence maps
6. Findings
7. Outputs
8. Interpretation / limitations
9. Reproducibility
10. Related research

The visual system is shared across projects while the analytical workflow remains project-specific.

## SEL-001 methodology

The current published architecture uses **35 indicators**, followed by:

`35 Indicators → Normalised Indicator Scores → URAF / Contextual Adjustment → Weighted Indicator Scores → 7 QOL Themes → Small Area QOL Index → 18,919 Small Areas`

Before publishing, verify that the 35-indicator definition is consistent with the underlying database, indicator catalogue, maps and reports.
